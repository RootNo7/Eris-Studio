# ERIS Experiments

Every meaningful experiment receives an ID.

Example:

EXP-0001

## Record

### Objective
What are we trying to learn?

### Hypothesis
What do we expect?

### Configuration
Architecture, parameters and relevant settings.

### Data
Dataset/version/provenance.

### Hardware
Exact hardware profile.

### Code
Repository commit/version.

### Cost
Time and cloud cost where applicable.

### Results
Measured results only.

### Interpretation
What does the evidence mean?

### Decision
What happens next?

Failed experiments remain recorded.
