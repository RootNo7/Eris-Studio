# ERIS Security

Security is part of the architecture.

## Principles

- least privilege
- sandboxing
- isolated execution
- secret protection
- explicit permissions
- safe defaults
- auditability

## Permissions

Systems may have permissions such as:

- filesystem
- network
- model access
- tools
- training
- deployment
- environments

Do not grant broad permissions by default.

## Environments

Gaming and experimental environments should be isolated where appropriate.

Never expose secrets through logs, model outputs or generated code.
