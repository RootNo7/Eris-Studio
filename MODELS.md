# ERIS Model Registry

Every meaningful model is registered here or through the model registry system.

## Required information

- ID
- name
- family
- version
- status
- purpose
- architecture
- parameters
- datasets
- dependencies
- capabilities
- limitations
- evaluations
- checkpoint
- deployment targets

## Status

Possible statuses:

PROPOSED
RESEARCH
EXPERIMENTAL
TRAINING
EVALUATION
STABLE
DEPRECATED
ARCHIVED

## Model creation

A new model should have a technical justification.

Proposal should explain:

- capability required;
- why existing models are insufficient;
- alternatives;
- expected benefit;
- data requirements;
- compute requirements;
- maintenance cost.

Major new model creation requires project-owner approval.

## Naming

Model names should be:

- unique;
- professional;
- memorable;
- technically meaningful;
- reasonably friendly.

Avoid meaningless naming schemes.
