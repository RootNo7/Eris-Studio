# ERIS Evaluation

Evaluation must measure actual capability.

## Rules

- use appropriate benchmarks;
- protect evaluation data from training contamination;
- record exact model/version;
- record evaluation configuration;
- preserve results;
- compare versions carefully;
- report limitations.

## Regression

A new model version must not be considered automatically better because one metric increased.

Track meaningful capabilities over time.

Example:

Capability A ↑
Capability B ↓
Capability C unchanged

This should be visible before stable release.
