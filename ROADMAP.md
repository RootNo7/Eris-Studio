# ERIS Roadmap

## NOW

Build the smallest practical foundation.

Focus on:

- repository structure
- development infrastructure
- first model
- training pipeline
- evaluation
- experiment tracking
- reproducibility
- deployment foundation

## NEXT

Expand based on measured results.

Potential areas:

- specialist models
- shared infrastructure
- model communication
- ERIS Studio
- improved training
- deployment
- memory/tools
- virtual environments

## VISION

Long-term possibilities:

- large multimodal AI ecosystem
- advanced model cooperation
- persistent learning
- virtual worlds
- digital embodiment
- personal AI assistants
- large-scale research infrastructure
- broader ERIS organization

The roadmap may evolve from evidence.

Important changes must be documented rather than silently made.
